## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/keketsoleu25/the-tech-alchemy-lab.git
```

### Navigate into the project

```bash
cd the-tech-alchemy-lab
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
