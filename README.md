# The Tech Alchemy Lab

The agency website for The Tech Alchemy Lab, rebuilt with the same modern stack used across its full-stack products.

## Current phase

Phase 3 adds a filterable portfolio and four statically generated dynamic case-study routes on top of the verified hero and services experience. The original static implementation remains in `legacy/` as a content reference while each remaining section is migrated and verified.

## Stack

- Next.js 16 with App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Vercel

Resend and persistent enquiry storage will be added during the dedicated contact-form phase.

## Local development

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`.
